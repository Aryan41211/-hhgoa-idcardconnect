# Brand Notes (from provided templates)

Pulled directly from `solo_final.png` and `squad_final.png`. Verify against the live HH Goa site/socials if anything's ambiguous — don't guess further than what's visibly in the templates.

## Palette

- Deep forest green — dominant background
- Hot pink / magenta — accents, tags, "BUILDER" pill, borders
- Yellow/gold — "HH GOA" wordmark, "2026", stamps, small icons
- Cream/off-white — torn-paper card blocks holding text (name, stack, tagline)
- Photo-slot gradient — pink-to-teal diagonal gradient as placeholder before a real photo loads

## Type

- Bold, condensed, all-caps display face for "HH GOA", "THE BUILDERS Are Here.", section headers — closest free equivalents: Anton, Archivo Black, or Bebas Neue
- Monospace-leaning label face for small tags ("BUILDER ID", "MADE FOR BUILDERS.", barcode-style numbers) — a mono font (e.g. Space Mono, JetBrains Mono) reads closest to the template
- Script/handwritten accent for "Are Here." in the squad template — treat as a one-off decorative flourish, not a body font

## Layout motifs (reuse these, don't invent new ones)

- Torn-paper / taped-corner card edges for text blocks
- Rotated washi-tape strips and pushpins as decorative overlays on photo corners
- Small scattered doodles: compass/crosshair icon, palm tree, stars, dotted travel-line path, birds
- Circular "stamp" badge (palm tree + "HACKER HOUSE GOA") — reusable as a small on-image seal
- Diagonal barcode + "BUILDER ID / 001" strip on the right edge (solo template) — a nice place to inject a real per-user ID number
- Bottom-left `#FRAMEINGOA` hashtag chip — must appear on every generated output, this is the whole point of the share requirement

## Required on-image elements (don't drop these compositing the final export)

- HH GOA wordmark + 2026 + "GOA, INDIA" tag
- `#FrameInGoa` hashtag visible on the graphic itself, not just the tweet caption
- The photo slot with real user photo (not the smiley/"TEST PHOTO" placeholder — obviously, but double check no template layer is stuck on top hiding it)
- Format B only: name, stack/role, generated builder title, team tagline (squad) / builder tag (solo)
